# WordPaper · 把单词做成你的壁纸

把**每天的单词**和**当天提醒事项**，做成手机 / 电脑壁纸的小网站。每天自动换一组单词，可手动刷新；内置 **8 个考试核心词库**（初中 / 高中 / 四级 / 六级 / 考研 / 雅思 / 托福 / GRE，每库 1500–3000 词），也能导入自己的单词表（CSV / Excel / 粘贴 / 截图 OCR / 手动添加）。

**纯前端、零构建、零运行时依赖**，数据全在浏览器 `localStorage`。

## 快速开始

```bash
node server.js          # http://localhost:8770（端口被占自动 +1）
python3 scripts/e2e.py  # 端到端验证（43 项断言，自带独立端口，不碰 8770）
```

打开网页 → 左侧选词库 / 版式 / 尺寸 / 主题 / 字体，右侧实时预览 → 在预览上**直接拖动**单词块、提醒块、自定义文字摆位置 → 「下载 PNG」存图去设为壁纸，或「进入实时壁纸」把它铺满屏幕当交互壁纸。

## 功能

- **两种版式**：单词组（N 个词 + 提醒清单）/ 大字海报（单个词 + 释义 + 例句）。
- **多种尺寸**：手机 20:9 / iPhone / 16:9，电脑 FHD / 2K / 4K，平板，自定义宽高。
- **整个排版可视化拖拽**：单词块、提醒块、自定义文字都能在预览上按住拖到**任意位置**（横竖都行）；锚点预设（靠上 / 居中 / 靠下）真的会移动整块。
- **字体风格 + 文字颜色**：黑体 / 宋体 / 楷体 / 圆体 / 粗黑 五种系统字体风格，文字颜色可跟随主题、选色板或自定义（只用本地系统字体，下载的 PNG 在别的机器上也不变样）。
- **自定义背景照片**：上传自己的照片铺满壁纸（cover-fit），上方自动加一层浅留白保证文字可读——想要放松、专注的背景就用自己拍的。
- **自定义文字**：顶部标题 / 底部落款，开启后在预览里直接拖到想要的位置。
- **每日自动刷新**：跨天自动换一组（同一天内保持稳定）；可选「定时轮换」按分钟滚动。
- **提醒事项**：手动添加 / 预置常用项一键加入 / 可带时间点并显示倒计时。
- **词库**：初中(1.5k)、高中(2k)、四级(2.5k)、六级(2.5k)、考研(2.8k)、雅思(3k)、托福(3k)、GRE(2.5k) 核心词 + 自定义导入。
- **导入**：CSV / Excel(.xlsx) / 直接粘贴 / **截图拍照 OCR** / 手动单个添加，自动去重。
- **主题**：奶油 / 薄荷 / 天空 / 樱花 / 夜空 / 森林。
- **实时壁纸模式**：铺满屏幕；**防误触**（默认长按 1.2s 才能唤出操作）；到点自动翻到下一天。
- **桌面伴侣**（可选，零安装）：网页里点「**一键启用**」就行——server 就运行在你自己的 Mac 上，会直接拉起伴侣：把壁纸设到桌面并定时更换、开一个无边框置顶小窗看今日单词、给网页提供「截图导入」的 OCR。**不用下载、不用解压、不用敲命令**。没在本机跑网站的话，也有「下载独立版」兜底（zip：解压 → 双击「启动伴侣.command」）。

## 数据与脚本

```bash
python3 scripts/build_wordlibs.py   # 从 ECDICT 重新生成 data/words_*.json
python3 scripts/render_v3.py        # v3 渲染验证：真渲染 PNG 到 scripts/out_v3/ 并做像素级断言
```

词库来自免费的 [ECDICT](https://github.com/skywind3000/ECDICT)，按考试标签过滤 + 按「核心度」排序（柯林斯星级 + 词频），取每库最高频的核心词。JSON 在 `data/`，schema：`{word, phonetic?, pos?, meaning?, example?, topic?}`，空字段省略。
